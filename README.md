# 🚦 Intelligent Traffic Signal Control Simulation

An AI-powered, real-time traffic management system that integrates machine learning and computer vision to optimize traffic signal timings, improve traffic flow, and enhance road safety through collision detection.

---

## 🎯 Project Goals & Key Objectives

The **Intelligent Traffic Signal Control Simulation** aims to develop a smart urban traffic management framework leveraging real-time data analytics, adaptive algorithms, and visual monitoring.

- 🚦 **Adaptive Signal Control:** Dynamically adjusts signal timings in real time based on current traffic density and queue lengths.
- 🚗 **Collision Detection:** Leverages computer vision algorithms to detect potential collision scenarios and enable immediate preventive intervention.
- 🛣️ **Improved Traffic Flow:** Significantly reduces congestion, intersection delays, and travel times through intelligent cross-intersection signal coordination.
- 🛡️ **Enhanced Safety:** Minimizes accident risks by alerting and proactively managing dangerous traffic situations.
- 📊 **Data-Driven Insights:** Captures and analyzes continuous traffic metrics to support long-term urban planning and smart city infrastructure design.

---

## 🚀 Steps to Run the Project

Follow the steps below to execute the traffic simulation on your local system:

### Step 1: Open the Project
Open the project directory in **Visual Studio Code (VS Code)** and navigate to the `simulation.py` file.

### Step 2: Open a New Terminal
In VS Code, open an integrated terminal by clicking:
`Terminal` ➡️ `New Terminal` (or press `Ctrl + \`` / `Cmd + \``).

### Step 3: Run the Simulation
Execute the script using Python:
```bash
python simulation.py
```

### Step 4: Install Required Packages (If Prompted)
If the system prompts that required packages (such as `pygame`) are missing, install them via `pip`:
```bash
pip install pygame
```
*Note: Install any additional dependencies mentioned in the prompt (e.g., `opencv-python`, `numpy`) using `pip install <package_name>`.*

After installing the required packages, re-run **Step 3**:
```bash
python simulation.py
